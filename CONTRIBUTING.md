# Contributing to kobe

kobe is a pure, offline HD wallet generator: one `no_std + alloc` library crate
(`crates/kobe`) plus a CLI crate (`crates/kobe-cli`, binary `kobe`). No signing,
no vault, no storage, no network.

Agents: read [`AGENTS.md`](AGENTS.md) for the architecture invariants. Process
lives here.

## Principles

| Rule | Meaning |
| ---- | ------- |
| Small PRs | One problem per PR; reviewable diffs. |
| No invented APIs | Follow the existing `Chain`/`Style`/`Account` contract. |
| No compatibility debt | Remove obsolete paths; no dual APIs or migrations "for now". |
| Secrets hygiene | Mnemonics, seeds, private keys: `Zeroizing` buffers, redacted `Debug`. Never `#[derive(Debug)]` on secret-bearing types. |
| Independent vectors | Every chain and style is pinned to official or third-party reference vectors — never a dump of our own previous output. |

License: contributions are dual-licensed [MIT](LICENSE-MIT) OR
[Apache-2.0](LICENSE-APACHE) as stated in `README.md`.

## Prerequisites

- **Rust 1.99** — pinned by `rust-toolchain.toml` (with the `thumbv7m-none-eabi`
  and `wasm32-unknown-unknown` targets).
- **cargo-deny** — `cargo install cargo-deny --locked` for the supply-chain gate.
- **Bun** — only needed to regenerate vectors (`scripts/vectors`).

## Local gate

Run the full gate before opening a PR:

```bash
cargo fmt --all --check
cargo clippy --workspace --all-targets --all-features -- -D warnings
cargo clippy -p kobe --all-targets --no-default-features -- -D warnings
cargo clippy -p kobe --all-targets --no-default-features --features all-chains -- -D warnings
cargo test --workspace --all-features
RUSTDOCFLAGS="-D warnings" cargo doc --workspace --no-deps --all-features
cargo build -p kobe --no-default-features --features all-chains --target thumbv7m-none-eabi
cargo build -p kobe --no-default-features --features all-chains --target wasm32-unknown-unknown
cargo tree -p kobe --no-default-features --features all-chains -e normal | grep getrandom   # must be empty
cargo deny check
cargo package --workspace --allow-dirty --no-verify
```

A new chain feature must also pass alone:

```bash
cargo clippy -p kobe --no-default-features --features <chain> --all-targets -- -D warnings
```

## Vectors

`vectors/<chain>.json` files are generated by the isolated Bun project in
`scripts/vectors` (exact-pinned reference packages, each release at least 7
days old). Regenerate after changing any chain:

```bash
cd scripts/vectors
bun install
bun run generate
```

Official spec vectors (BIP-32/39/84/86, SLIP-10, NIP-06, SEP-0005, CIP-3,
cashaddr, rusty-kaspa) are copied verbatim — do not "fix" them; fix the code.
Rust tests in `crates/kobe/tests/vectors.rs` assert `path`, `address`,
`public_key`, `private_key`, and `extra` byte-for-byte. A chain is not done
until its vectors pass.

### Second-source check

```bash
cargo build -p kobe-cli && cd scripts/vectors && bun run crosscheck
```

Re-derives every CLI account with Trust Wallet Core (C++/WASM) — a source
independent of the reference packages behind `vectors/` — and checks every
path against an independently written template table; it must end with
`0 failures`. Wallet Core lacks kaspa, nostr, spark, casper, TON V5R1 and
the Ledger/Trezor Cardano masters, and ignores the BIP-39 passphrase for
Cardano; those cases rely on `vectors/` alone.

## Adding a chain

1. `crates/kobe/src/chains/<chain>.rs` — one `Chain` impl: option enums via
   `option_enum!`, `styles()` as `Style::new(...)` lines, `derive()`; wire the
   module in `crates/kobe/src/chains/mod.rs` behind its feature. Canonical
   name = module = feature = CLI command.
2. Feature flag in `crates/kobe/Cargo.toml` (`<chain> = [...]` minimal deps)
   and in `all-chains`.
3. CLI variant in `crates/kobe-cli/src/cli.rs` (`Command` + clap args over
   the library enums) and a `spec()` arm in `crates/kobe-cli/src/target.rs`.
4. Reference vectors: extend `scripts/vectors/generate.ts`, regenerate, and
   cover every style and every option variant (networks, kinds, contracts,
   presets) at indices 0–2 for the 12-word, 24-word, and passphrase seeds.
5. Rust test in `crates/kobe/tests/vectors.rs` asserting every field
   byte-for-byte; CLI smoke case in `crates/kobe-cli/tests/cli.rs`.
6. A row in the `docs/chains.mdx` chain/style and output tables.

## Releasing

Tag `vX.Y.Z` — `release.yml` builds the `kobe` binaries and
`publish-crates.yml` publishes `kobe` then `kobe-cli` to crates.io.
Versions are workspace-lockstep (`[workspace.package].version`).
