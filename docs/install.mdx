---
title: Install
description: Install the kobe CLI, the kobe crate, and the @qntx/kobe package.
---

CLI:

```bash
curl -fsSL https://sh.qntx.org/kobe | sh
```

```powershell
irm https://sh.qntx.org/kobe/ps | iex
```

```bash
cargo install kobe-cli
```

Library (enable chains explicitly):

```toml
kobe = { version = "4", features = ["std", "evm", "btc", "svm"] }
```

TypeScript:

```bash
bun add @qntx/kobe
```

(or `npm install @qntx/kobe`). The package is subpath-only — there is no root
entry; import from `@qntx/kobe/core`, `@qntx/kobe/nostr`, or
`@qntx/kobe/vault`.
