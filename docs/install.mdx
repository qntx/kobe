---
title: Install
description: Install the kobe CLI, the kobe crate, and the @qntx/wallet package.
---

CLI:

```bash
curl -fsSL https://sh.qntx.org/kobe | sh
```

```powershell
irm https://sh.qntx.org/kobe/ps | iex
```

```bash
cargo install kobe-cli
```

Library (enable chains explicitly):

```toml
kobe = { version = "4", features = ["std", "evm", "btc", "svm"] }
```

TypeScript:

```bash
bun add @qntx/wallet
```

(or `npm install @qntx/wallet`). The package is subpath-only — there is no root
entry; import from `@qntx/wallet/hd`, `@qntx/wallet/evm`, `@qntx/wallet/svm`,
`@qntx/wallet/btc`, `@qntx/wallet/nostr`, `@qntx/wallet/sign`, or
`@qntx/wallet/vault`.
