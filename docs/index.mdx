QuantX's multi-chain wallet library: BIP-39 wallets, per-chain HD derivation
and addresses, wallet ids, the vault format (envelope, KDF, passkey
PRF-derived wallets), and Nostr NIP-06 derivation plus `nsec`/`npub`
encoding. Implemented twice — Rust crates and the TypeScript package
`@qntx/kobe` — kept in lockstep by shared `vectors/`; the library crates are
`no_std` + `alloc`. The CLI binary is `kobe` (`kobe-cli`).

Transaction and message signing lands in 4.1 by merging
[signer](https://github.com/qntx/signer) into this workspace.

```bash
kobe evm new
```
