---
title: kobe
description: Multi-chain HD wallet derivation from one BIP-39 seed.
---

`kobe` derives HD accounts from a BIP-39 mnemonic. Library crates build under `no_std` + `alloc`. The CLI binary is `kobe` (`kobe-cli`).

Companion signer: [signer](https://github.com/qntx/signer) (`Signer::from_derived`).

```bash
kobe evm new
```
